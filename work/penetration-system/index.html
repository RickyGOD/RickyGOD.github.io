SELECTED WORK / RICKY LIU

穿射系统｜让规则成为关卡设计工具

把材质、厚度与反馈统一成玩家可预测的规则，并在 Layout 阶段提前表达掩体的穿射意图。
CASE INDEX01 / 问题：玩家需要预测结果02 / 决策：统一规则，再交给空间03 / 反馈：让结果一眼可读

我的职责：穿射规则整理、材质反馈需求，以及关卡内穿射意图的定义与交付。

问题：玩家需要预测结果

如果同类箱体和墙面在不同位置表现不一致，玩家就很难建立稳定预期。对关卡来说，穿射规则越不可读，掩体强度也越难被玩家理解。

决策：统一规则，再交给空间

整理标准箱与普通墙面的穿射规则，以材质、厚度和实际穿透距离作为主要判断依据；Layout 阶段先标记希望支持穿射的结构，再与场景制作对齐。

反馈：让结果一眼可读

补充水泥、铁、木等材质的弹痕表现，并区分可穿与不可穿反馈。穿射因此不仅是武器规则，也能成为调整防守位置强度的 Level Design 工具。

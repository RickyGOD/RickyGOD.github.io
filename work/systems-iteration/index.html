训练场：仅评分与成长反馈子系统

问题：单次打靶结束后，玩家很难直观看到自己的水平和变化。

我的部分：负责难度等级、评分逻辑、成绩表现、历史 / 平均表现对比，以及红绿升降反馈；同时对接 UI / 交互需求并跟进功能落地。

这项职责不包含整个训练场，也不包含圆靶、人形靶或距离靶场的主体设计。现有素材尚不足以单独做完整 Case，因此这里只保留准确的工作边界。

其他地图支持

TDM 完整地图与休闲广场投掷对抗白盒均为本人实际负责，但现有归档缺少足够公开素材。网站暂不使用其他项目画面代替，后续补充 Layout / Whitebox 后再扩展为独立内容。
